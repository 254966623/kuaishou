# 用法二：没有电脑，用聊天 AI 维护词库（对应 adcleaner docs/03）

## 什么时候用
- 弹窗关不掉、按钮找不到 → 界面改版，本地词库失效
- 想加新的金币活动入口（饭补、看广告得金币……）

## 怎么用
1. 停止服务，手动走到问题页面
2. 截屏 + 记下页面上关键文字
3. 把下面这段话发给 DeepSeek / 豆包（手机版即可）：

```text
我在做一个安卓无障碍自动化的词库维护。当前 rules.json 如下：
【粘贴 rules.json 全文】
现在快手弹了这样一个页面：【描述或截图】
页面上这些文字点不到或识别不到：【文字列表】
请只改 popup/close_words/signin/chest 四个数组，输出完整新版 rules.json，
不要改其他参数。
```

4. 它输出的 JSON 覆盖到 app/src/main/assets/rules.json，重打包安装
   （或 if 已 root 直接替换 assets 后强停重开服务）

## 硬规则（同样约束 AI）
- 不允许把任何 danger 词（充值/支付/购买）移出数组
- 不允许改 dwell/swipe 的随机化区间（改匀速 = 找封）
